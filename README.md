# 404 Error Page 🚀

A creative and responsive 404 error page built using HTML5 and CSS3.

## About the Project

This project displays a friendly error message when a user visits a page that cannot be found. It uses a simple space-themed design with a floating planet illustration and pastel colors.

## Features

- Custom 404 error message
- CSS planet illustration
- Floating animation
- Homepage navigation button
- Responsive design
- Pastel gradient background
- Smooth hover effects

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Project Structure

404-error-page/

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Explore the 404 error page.
